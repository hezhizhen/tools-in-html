# Refactor: index.html

## Context

The index.html is the landing page for the "Tools in HTML" project. It displays a grid of tool cards, each linking to a single-file HTML tool. The current file works correctly but has semantic and accessibility issues compared to best practices observed in the rest of the codebase.

## Goal

Improve semantic HTML and accessibility without changing the visual design.

## Changes

### 1. Semantic HTML
- Replace `<span class="tool-name">` → `<h2 class="tool-name">` (proper heading hierarchy: h1 page title, h2 tool names)
- Replace `<span class="tool-desc">` → `<p class="tool-desc">` (descriptions are paragraphs, not inline text)

### 2. Accessibility
- Add `aria-hidden="true"` to emoji icon spans (decorative, not meaningful to screen readers)
- Add `<main>` wrapper around the container div (landmarks for screen readers)

### 3. CSS alignment
- Align the body background gradient with the rest of the tool pages:
  - Current: `linear-gradient(135deg, #0f0f23 0%, #1a1a3e 100%)`
  - Other tools: `linear-gradient(135deg, #1a1a2e 0%, #16213e 100%)`
- Update `h2.tool-name` style to reset heading defaults (margin, font-size) to match current `span.tool-name` appearance
